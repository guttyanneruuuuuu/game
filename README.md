# ORBITAL SLASH — 軌道斬

無限軌道を駆け、光の核を斬り続ける、永遠に続くフロー系3Dアクションゲーム。

**▶ Play: https://guttyanneruuuuuu.github.io/game/game/**

## 操作方法

### スマホ
- **スワイプ** … 斬撃(光の核を斬る)
- **端末を傾ける** … 重力を歪めて軌道を移動(GYROボタンで有効化)
- **二本指タップ長押し** … 時間減速(ブレットタイム)
- **DASHボタン** … 一気に加速して突進
- **BURSTボタン** … エネルギー満タンで全画面斬撃(必殺技)

### PC
- **マウスドラッグ** … 斬撃
- **WASD / 矢印キー** … 移動
- **Space** … ダッシュ
- **Shift** … 時間減速
- **B** … バースト
- **HAND-CAMボタン** … MediaPipeで手の動きを認識して移動操作

## 特徴

- **完全独自の3Dアクションフロー**: 既存のランナー / リズム / 斬撃ゲームを融合した新ジャンル
- **滑らかなグラフィック**: ブルーム / クロマティックアベレーション / フィルムグレイン / ビネット / FXAA を組み合わせた高品質ポストプロセス
- **モバイル最適化**: タッチ + ジャイロ + マルチタッチを統合した直感操作
- **MediaPipe Hands 統合**: カメラに手をかざすだけで操作できる革新的な体験(オプション)
- **ジェネラティブBGM**: WebAudioでリアルタイム生成される無限のアンビエント音楽
- **3つのモード**: ENDLESS(永久) / RUSH(高速) / ZEN(瞑想)
- **アセット不要**: HTMLファイル1つだけ、すべてプロシージャル生成 — 即座に開いて遊べる

## 技術

- Three.js (r160) + EffectComposer 後処理
- @mediapipe/tasks-vision (手のランドマーク検出)
- WebAudio API (シンセサイザBGM/SFX)
- DeviceOrientation API (ジャイロ操作)
